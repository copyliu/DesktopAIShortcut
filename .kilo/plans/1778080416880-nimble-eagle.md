# 计划：完善基础聊天功能 + 提示词预设支持

## 目标
实现完整的聊天流程：用户选择模型 + 选择提示词预设 → 发送消息 → AI 根据提示词上下文回复 → 聊天记录自动保存。

## 当前缺陷
1. MainWindow 提示词预设 ComboBox 绑定到错误的 `ModelList`，而非 `PromptTemplates`
2. 选择提示词预设后未同步到 ChatHistoryViewModel
3. 发送消息时未将提示词的 PrefixMessages/SuffixMessages 注入到 AI 请求中
4. 聊天记录不会自动保存（ChatHistoryService 未被调用）
5. ChatHistoryService 构造函数中 `savefolder` 未赋值给实例字段（Bug）
6. ChatHistoryViewModel 有废弃 TODO 注释（`//TODO: client????`），移除该注释，但保留所有字段（_title/_createTime/client 预留给将来使用）
7. 新建聊天时侧边栏标题显示为空，需要占位标题

---

## Step 1: 修复 ChatHistoryService 构造函数 Bug
**文件**: `DesktopAIShortcut/Services/ChatHistoryService.cs:26`

问题：`var savefolder = ...` 是局部变量，实例字段 `this.savefolder` 始终为 null，导致所有保存/加载操作静默失败。

**修改**: `var savefolder` → `this.savefolder`

## Step 4: 添加聊天自动保存逻辑
**文件**: `DesktopAIShortcut/ViewModels/ChatHistoryViewModel.cs`

```csharp

```

## Step 6: 在发送消息时注入提示词上下文
**文件**: `DesktopAIShortcut/ViewModels/ChatHistoryViewModel.cs`

修改 `AddUserMessageAsync`，构建发送给 AI 的消息列表时：
1. 先在列表头部插入 `SelectedPromptTemplate.PrefixMessages`（system/assistant/user 预设上下文）
2. 然后在尾部追加 `SelectedPromptTemplate.SuffixMessages`
3. 将构造好的完整列表传给 `OpenAIAdapter.SendMessageAsync`

**不将 PrefixMessages/SuffixMessages 显示在 UI 中**，仅注入到 API 请求。
